# Olist SQL Data Analysis

## 📌 Project Overview

This project analyzes the Brazilian Olist e-commerce dataset using **MySQL**.

The analysis focuses on customers, orders, order items, payments, reviews, products, sellers, geolocation, and product categories to generate meaningful business insights using SQL.

## 🛠️ Tools & Technologies

- MySQL
- MySQL Workbench
- SQL
- GitHub

## 📂 Dataset

The project uses the Olist Brazilian E-Commerce Public Dataset.

The dataset contains multiple tables including:

- Customers
- Orders
- Order Items
- Order Payments
- Order Reviews
- Products
- Sellers
- Geolocation
- Product Category Translation

## 🔍 SQL Analysis Performed

The project includes 15 SQL queries covering:

1. Basic SELECT
2. Selecting specific columns
3. Filtering data using WHERE
4. Sorting data using ORDER BY
5. Aggregate functions
6. GROUP BY analysis
7. GROUP BY with HAVING
8. INNER JOIN
9. LEFT JOIN
10. Three-table JOIN
11. Revenue by state
12. Average order value
13. Product categorization using CASE
14. Finding duplicate reviews
15. Top 10 product categories
